--------------------------------------------------------------
DNA HELIX COMPONENT (DNAHelix.jsx) — The centerpiece
--------------------------------------------------------------

CONCEPT:
  Modules alternate LEFT and RIGHT down the page connected
  by a curved SVG strand that twists like a DNA double helix.
  The strand itself is the visual backbone, modules are the
  "base pairs" extending outward from the center spine.

STRUCTURE (per module):
  - Central vertical spine: 4px wide, gradient purple→cyan→pink
  - Each module has:
      → A connector arc curving from spine to card
      → A dot on the spine (12px circle, gradient bg)
      → A RoadmapCard on alternating left/right sides
  - Connecting "rungs" between left and right dots:
      thin horizontal lines like DNA base pairs
      gradient from left accent to right accent
      opacity: 0.3

SVG STRAND:
  - Two sinusoidal SVG paths running down the center
  - Path 1: curves left-center-right-center (purple stroke)
  - Path 2: same but offset by half period (cyan stroke)
  - Both paths: stroke-width 2, fill none, opacity 0.6
  - On page load: animate stroke-dashoffset from full length to 0
    (draws itself downward over 1.5s ease)

SPINE DOT (per module):
  - 14px circle, bg: gradient purple → cyan
  - white 3px ring around it
  - Slight glow: box-shadow 0 0 12px rgba(139,92,246,0.6)

CONNECTOR ARC (per module):
  - SVG curved path from spine dot to card edge
  - Stroke: module's accent color, stroke-width: 1.5, opacity: 0.5
  - Dashed: stroke-dasharray: 4 4

MODULE POSITIONS:
  - Odd modules: card on LEFT side, connector arcs left
  - Even modules: card on RIGHT side, connector arcs right
  - Vertical spacing between modules: ~180px
  - Cards offset from center: ~180px left or right

CARD ENTRANCE ANIMATION:
  - Odd (left) cards: slide in from left (translateX(-40px) → 0)
  - Even (right) cards: slide in from right (translateX(40px) → 0)
  - Staggered: each card delays by index * 0.15s
  - Trigger: IntersectionObserver when card enters viewport

API ROUTES (for reference during frontend build)
=============================================================

POST /api/parse-resume     → { skills: [{name, level, category}] }
POST /api/parse-jd         → { skills: [{name, level, category}] }
POST /api/github-analysis  → { repos, languages, detectedSkills, stats }
POST /api/gap-analysis     → { missing: [], weak: [], strong: [] }
POST /api/generate-pathway → { modules: [{id, name, duration, skills, reasoning}] }
POST /api/regenerate       → same as generate but takes feedbackOptions + freeText

State flow between pages:
  onboard → store results in localStorage or Zustand/Context
  analysis page reads from store
  pathway page reads from store
  feedback triggers regenerate API call → updates store → re-renders pathway
